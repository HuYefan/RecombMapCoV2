# RecombMapCoV2 — SARS-CoV-2 recombinant lineage analysis code

[!\[Repository](https://img.shields.io/badge/code-RecombMapCoV2-blue)](https://github.com/HuYefan/RecombMapCoV2)

Analysis code for the computational figures of

> \*\*Recombination drives the emergence and immune escape of SARS-CoV-2 variant
> NB.1.8.1/XFG\*\* — Figures 1–2 and Supplementary Figures S1–S3.

**Code repository:** https://github.com/HuYefan/RecombMapCoV2

A summary of the algorithms implemented here and of every dataset generated by
this code is in [`docs/ANALYSIS\_SUMMARY.md`](docs/ANALYSIS_SUMMARY.md); the
figure legends it reproduces are those of `XFG\_Text\_Main Figs\_20260901a.docx`.

This repository contains the code that produces the **computational / genomic**
figures only:

|Figure|Panel|Content|Folder|
|-|-|-|-|
|**Fig. 1**|a|Global and regional prevalence of recombinant lineages over time|[`Figure\_1/a\_variant\_proportion`](Figure_1/a_variant_proportion)|
|**Fig. 1**|b|Recombination pathways of XBB, XDE, XDV, XEC, XFG|[`Figure\_1/b\_recombination\_pathways`](Figure_1/b_recombination_pathways)|
|**Fig. 1**|c–d|2,991 recombination breakpoint intervals and midpoint histogram|[`Figure\_1/cd\_recombination\_breakpoints`](Figure_1/cd_recombination_breakpoints)|
|**Fig. 1**|e|Uniformed recombination intensity along the genome|[`Figure\_1/e\_recombination\_intensity`](Figure_1/e_recombination_intensity)|
|**Fig. 1**|f–g|Hotspot mapping onto the spike structure|[`Figure\_1/fg\_structural\_mapping`](Figure_1/fg_structural_mapping)|
|**Fig. 2**|a–b|Sequence/structural features of recombination hotspots + statistics|[`Figure\_2`](Figure_2)|
|**Fig. S1**|a–b|Phylogenetic diversification of circulating variants, 2021–2026|[`Figure\_S1`](Figure_S1)|
|**Fig. S2**|a–j|Detailed nucleotide breakpoints and genomic recombination intensity|[`Figure\_S2`](Figure_S2)|
|**Fig. S3**|—|Correlation matrix (VCM) of recombination variables by region type|[`Figure\_S3`](Figure_S3)|

Wet-lab figures (3–8) and the cryo-EM/structural figures (S4–S12) are not part
of this repository.

## Data

Only inputs that directly produce Figures 1–2 and Supplementary Figures S1–S3
are kept, under [`data/`](data). Large primary source data are **not** bundled — see
[`data/README.md`](data/README.md) for the expected names, sizes and sources.
